Option A — custom connector (recommended)

  1. Open Claude Desktop and go to Settings → Connectors.

  2. Click Add custom connector.

  3. Name it sportbrobot and paste your MCP URL:

    {{ url }}

  4. Save. In a new chat, open the tools menu — you should see SportBroBot's tools listed.

Option B — config file

  1. Open claude_desktop_config.json:

    macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
    Windows: %APPDATA%\Claude\claude_desktop_config.json

  2. Add SportBroBot under mcpServers (Claude Desktop's config route uses mcp-remote to bridge to remote servers):

    {
  "mcpServers": {
    "sportbrobot": {
      "command": "npx",
      "args": ["mcp-remote", "{{ url }}"]
    }
  }
}

  3. Fully quit Claude Desktop and start it again — a window close is not enough.

  4. Ask something like "How did I sleep last night?" and approve the tool call.

{% elif client == 'claude-code' %}

Add the server

  1. In a terminal, run:

    claude mcp add --transport http sportbrobot "{{ url }}"

  2. Prefer editing config by hand? Add this to ~/.claude.json instead:

    {
  "mcpServers": {
    "sportbrobot": {
      "type": "http",
      "url": "{{ url }}"
    }
  }
}

  3. Start claude and run /mcp — SportBroBot should show as connected.

  4. Try: "Summarize my last three runs and tell me if my training load is trending up."

{% elif client == 'cursor' %}

Add the server

  1. Open Cursor Settings → MCP and click Add new MCP server (or edit ~/.cursor/mcp.json directly).

  2. Use this configuration:

    {
  "mcpServers": {
    "sportbrobot": {
      "url": "{{ url }}"
    }
  }
}

  3. Save and check the MCP settings page — the server indicator should turn green with the tool list expanded.

  4. In the agent panel, ask: "What does my HRV trend look like this month?"

Troubleshooting

401 Unauthorized
Your token was probably rotated. Copy the full URL from your dashboard again — the apiKey part is what authenticates you.
Connected, but tools return no data
Connect your Garmin account on the dashboard first — the tools read live from your Garmin link.
The server doesn't show up at all
Fully restart the client after changing config files, and double-check the URL wasn't truncated when pasting.

Try asking

  • Summarize my last three runs.
  • Am I ready for a hard workout tomorrow?
  • What race time do I project for a 10K?
